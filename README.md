## 🇨🇳 中文

根据用户意图、工作流或已完成的对话，创建、修改、安装、管理或复用双语 Skill，产出对齐的运行时文件与市场元数据。当你希望换一组输入重复走完某个已完成流程时，也可以用它把流程固化下来。它清楚区分两类目录：市场安装的 Skill 由应用自动管理、不该手改，用户创建或编辑的 Skill 完全由自己掌控；同名时用户目录的版本优先生效。从市场安装走应用内的 Skill 广场，安装后存放在市场目录并在列表启用，支持自动更新。

### ✨ 能做什么

- 捕捉意图 → 生成 SKILL.md 与对齐的双语市场元数据
- 三种使用场景：新建 Skill、改造已有 Skill、把已完成流程固化复用
- 从市场安装 Skill，安装后在列表启用并自动更新
- 区分市场目录与用户目录，同名时用户版本优先
- 更新与配置已有 Skill，管理已装技能清单
- 判断哪些内容值得保存为 Skill，避免把一次性细节写进去

## 🇬🇧 English

Creates, edits, installs, manages and reuses bilingual Skills from user intent, a workflow or an already-finished conversation, producing aligned runtime files plus marketplace metadata. It is also the tool when you want to repeat a completed process with a different set of inputs. It keeps two directories apart: marketplace-installed Skills are managed by the app and should not be hand-edited, while user-created ones are fully under your control, and the user copy wins when names collide. Marketplace installs go through the in-app Skill square, land in the managed directory, are enabled from the Skill list and support automatic updates.

### ✨ What it does

- Captures intent, then generates SKILL.md plus aligned bilingual marketplace metadata
- Three use cases: create a Skill, revise an existing one, or freeze a finished process for reuse
- Installs Skills from the marketplace, then enables them in the list with automatic updates
- Separates the marketplace directory from the user directory, with the user copy winning on name collisions
- Updates and configures existing Skills and manages the installed inventory
- Judges what is worth saving as a Skill so one-off details stay out

### 📦 Skills included

- `skill-creator` — [`skill-creator/SKILL.md`](skill-creator/SKILL.md)

### 🚀 Install

```bash
git clone https://github.com/yzsp-studio/skill-creator.git
cp -r skill-creator/* "$DSH_HOME/skills/"
```

> Skills are **plain-text instructions** (`SKILL.md` + `references/`). Zero dependencies, no API keys — they run on your agent's existing session quota.
